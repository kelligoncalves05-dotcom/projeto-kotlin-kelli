# Sistema de Cadastro e Login + Desafio Target Sistemas - Python

Meu primeiro sistema completo feito no celular com Pydroid 3!
Projeto criado como parte da minha transição de Gestão Comercial / Inside Sales para Dev - cursando ADS.

### 🚀 Tecnologias:
- Python
- Pydroid 3
- Validação de e-mail e senha
- Estrutura de dados com List e Dict
- UUID
- Git & GitHub Mobile

### ✨ Funcionalidades - Sistema Cadastro:
- ✅ Cadastrar novo usuário com validação
- ✅ Impedir e-mail duplicado
- ✅ Login com autenticação
- ✅ Listar usuários cadastrados
- ✅ Validação de senha (mínimo 6 caracteres)

### 💼 Desafio Target Sistemas:
- ✅ Cálculo de Comissão: 5% até R$1000, 10% até R$5000, 15% acima
- ✅ Controle de Estoque com UUID: ID único para cada produto
- ✅ Juros Compostos: Cálculo de montante

### 💡 O que aprendi:
Estrutura de dados e controle de fluxo com for e if, funções, validações e versionamento Git pelo celular.
